# Data Model — Portfolio Workflow Overhaul

## Entities

### IndexUniverse
- **Fields**
  - `name: str` — human-readable identifier chosen from available index files.
  - `source_path: Path` — filesystem path to `storage/index_universes/<name>.json`.
  - `as_of: date` — optional snapshot timestamp embedded in the JSON metadata.
  - `symbols: list[SymbolRecord]` — full list of candidates supplied by the JSON file.
- **Relationships**
  - One `IndexUniverse` aggregates many `SymbolRecord` instances.
- **Validation Rules**
  - `symbols` must be non-empty.
  - Ticker symbols must be unique within the universe.
  - JSON loading must fail fast with descriptive errors when schema mismatches.

### SymbolRecord
- **Fields**
  - `ticker: str`
  - `name: str`
  - `sector: str | None`
  - `industry: str | None`
  - `market_cap: float | None`
  - `coverage_status: CoverageStatus` — enum describing data completeness.
  - `coverage_window: DateWindow | None`
  - `median_price: float | None`
  - `median_dollar_volume: float | None`
  - `filters_applied: FilterSettings` — snapshot of thresholds used when selected.
- **Relationships**
  - Belongs to exactly one `IndexUniverse` during curation.
  - Contributes to `DraftPortfolio` and `SavedPortfolioArtifact`.
- **Validation Rules**
  - `ticker` must be uppercase alphanumeric (no spaces).
  - Price/volume fields require non-negative values when present.
  - Coverage window end date must be ≥ start date.

### FilterSettings
- **Fields**
  - `text_query: str`
  - `sectors: set[str]`
  - `market_cap_limit: float | None`
  - `price_floor: float | None`
  - `volume_floor: float | None`
- **Relationships**
  - Embedded inside `SymbolRecord` snapshots and `SavedPortfolioArtifact.metadata`.
- **Validation Rules**
  - Market cap, price, and volume thresholds must be positive when provided.
  - Sector list must be a subset of sectors present in the active universe.

### DateWindow
- **Fields**
  - `start: date`
  - `end: date`
- **Validation Rules**
  - `end` must be ≥ `start`.
  - Window length should not exceed 365 days (enforced to limit cache size).

### LiquiditySnapshot
- **Fields**
  - `ticker: str`
  - `median_price: float`
  - `median_dollar_volume: float`
  - `coverage_window: DateWindow`
  - `missing_fraction: float` — proportion of days without data.
- **Relationships**
  - Generated by `liquidity_fetcher` for each `SymbolRecord`.
  - Updates `SymbolRecord` and informs portfolio-level aggregates.
- **Validation Rules**
  - `missing_fraction` must lie within `[0, 1]`.
  - `median_price` and `median_dollar_volume` must be non-negative.

### DraftPortfolio
- **Fields**
  - `id: UUID` — ephemeral identifier for session tracking.
  - `universe_name: str`
  - `selected_symbols: list[SymbolRecord]`
  - `aggregates: PortfolioAggregates`
  - `filters_snapshot: FilterSettings`
  - `created_at: datetime`
- **Relationships**
  - Lives in Streamlit session state; may be persisted as `SavedPortfolioArtifact`.
- **Validation Rules**
  - `selected_symbols` must not contain duplicates.
  - Aggregates recalc required whenever selection changes.

### PortfolioAggregates
- **Fields**
  - `symbol_count: int`
  - `median_price_avg: float | None`
  - `median_dollar_volume_avg: float | None`
  - `coverage_gap_count: int`
- **Validation Rules**
  - `symbol_count` must match length of `selected_symbols`.
  - Count/average metrics recomputed from current selection only.

### SavedPortfolioArtifact
- **Fields**
  - `name: str` — researcher-provided label (case-insensitive).
  - `schema_version: str`
  - `universe_name: str`
  - `filters: FilterSettings`
  - `priors_window: DateWindow`
  - `symbols: list[SymbolRecord]`
  - `aggregates: PortfolioAggregates`
  - `shard_hints: ShardHints` — metadata about cache shards used.
  - `created_at: datetime`
  - `updated_at: datetime`
- **Relationships**
  - Persisted to `storage/portfolios/<normalized_name>.json`.
  - Overwrites earlier artifact when the same `name` is reused.
- **Validation Rules**
  - `schema_version` must match latest contract.
  - `symbols` list must not be empty.
  - `updated_at` ≥ `created_at`.

### PortfolioDeletionRequest
- **Fields**
  - `name: str`
  - `reason: str | None`
  - `requested_at: datetime`
- **Relationships**
  - Consumed by CLI/UI delete handlers to remove the stored artifact.
- **Validation Rules**
  - `name` must correspond to an existing artifact.

### ShardHints
- **Fields**
  - `cache_key: str` — identifier for the warmed OHLCV cache file/segment.
  - `segments: list[ShardSegment]` — coverage windows maintained for the cache.
- **Validation Rules**
  - Segment list MUST be non-empty.

### ShardSegment
- **Fields**
  - `symbol_count: int`
  - `start: date`
  - `end: date`
- **Validation Rules**
  - `symbol_count` must be ≥ 0.
  - `end` must be ≥ `start`.

## State Transitions

1. **Universe Loaded**: `IndexUniverse` and `SymbolRecord` objects created from JSON and cached for 15 minutes.
2. **Filtering Applied**: `FilterSettings` updates produce a derived subset of `SymbolRecord` instances; cached results updated.
3. **Liquidity Enriched**: `LiquiditySnapshot` values merge into `SymbolRecord` fields; `PortfolioAggregates` recomputed.
4. **Draft Portfolio Updated**: `SymbolRecord` selections mutate `DraftPortfolio.selected_symbols`, triggering aggregate recalculation.
5. **Portfolio Saved**: `DraftPortfolio` materializes to `SavedPortfolioArtifact`; file write overwrites any existing artifact with the same name.
6. **Portfolio Deleted**: `PortfolioDeletionRequest` leads to artifact removal and UI/CLI confirmation.
